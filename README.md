# Tomato-Disease-Dataset
The Tomato Disease dataset was constructed by integrating images collected from multiple greenhouses in Weifang City, Shandong Province, China, and publicly available images obtained from online sources. The greenhouse images were collected under practical tomato cultivation conditions, while the online images were obtained from publicly available resources. By combining images from different sources, this dataset provides diverse samples for evaluating tomato disease detection models under complex environments.

The dataset contains a total of 3,362 images, including 2,690 training images, 336 validation images, and 336 testing images. It covers eight tomato disease classes and one healthy class. The images present diverse variations in illumination conditions, leaf overlap, fruit occlusion, and disease severity, providing a challenging benchmark for tomato disease detection under different environments.

All images were annotated with bounding boxes using the LabelImg tool, indicating the location and category of tomato diseases. The annotations were manually verified to ensure accuracy and consistency. The dataset is provided in YOLO object detection format for model training and evaluation.
